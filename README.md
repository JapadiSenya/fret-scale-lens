# fret-scale-lens

弦楽器(ベース/ギター)のフレットボード上に音名を表示し、指定したキー・スケールに対応するフレット位置をハイライト表示するツールです。ビルド不要の静的Webページとして、GitHub Pages上で動作する想定です。

## 主な機能

- **フレットボード表示**: SVGで指板を描画し、各フレットの音名をオクターブまで含めて計算・表示
- **可変チューニング**: 弦数・各弦の開放音を自由に設定可能。ベース4弦/5弦・ギター6弦の標準チューニングをプリセットとして用意し、カスタムチューニングも組める
- **ネックポジションマーク**: 3・5・7・9・12(2つ)・15・17・19・21・24(2つ)フレットにインレイマークを表示
- **キー・スケールハイライト**: ルート音とスケール(メジャー/ナチュラルマイナー/メジャーペンタトニック/マイナーペンタトニック/ブルース)を選択し、該当するフレット位置を色分け表示
- **機能和声表示**: スケール構成音表示と、度数(ローマ数字)・トニック/サブドミナント/ドミナントの機能和声表示をトグルで切り替え可能
- **音声再生**: 弦・フレットをタップ/クリックすると、Web Audio APIでその場で合成した音を再生(音声ファイル不使用)。全発音は共通のマスター音量スライダーで調整可能
- **TAB譜作成・再生**: 指板をクリックしてTAB譜を作成・編集・再生できる譜面エディタ機能
  - **複数TAB譜の管理**: 画面上部のタブバーでTABを切り替え/新規作成/削除。TABごとに独立したチューニング(弦数・開放音)・フレット数を持てる(例: ベース用TABとギター用TABを別々に管理)。「+」ボタンでパート名・チューニングプリセットを指定して新規TABを作成。Undo/Redo履歴・選択範囲はTABごとに独立、コピー&ペーストのクリップボードはTAB間で共有
  - **曲名はグローバル**(画面上部で1つだけ設定)、**TABごとに持つのはパート名**(複数TABは「1つの曲を構成する複数パート」という位置付け)。テンポ(BPM)・拍子も全TAB共通のグローバル設定
  - **複数TABの同時再生**: 再生ボタン付近のチェックリストで同時に鳴らす他TABを選択可能。共通のテンポで同期して再生し(TABごとのチューニングはそのまま反映)、アクティブTABの選択位置(拍数換算)に他TABも自TAB内で対応する位置を合わせて開始するため、同時再生中でも選択位置からの再生が有効。アクティブTABが短くて先に演奏を終えた場合も、他TABが鳴り続けている間は「停止」ボタンのままとなり、いつでも全TABをまとめて止められる(このとき再生位置ハイライトのみ解除される)
  - 音符長(全音符〜16分音符)・付点、休符、ゴーストノート(✕表示、弦=ピッチごとのミュート属性)の入力
  - 和音(複数弦同時押さえ)入力: 「和音入力」トグル+単一選択中の音符へのクリックで(弦, フレット)を追加。同じ弦の再クリックでピッチを除去(トグル)。ゴーストトグルと組み合わせれば、1つの和音の中に通常のフレット音とミュート弦を混在させられる。既入力の複数音符を範囲選択して同じボタンを押すと、それらを1つの和音へ統合(同じ音符長・付点が揃っている場合のみ。ゴースト/通常の混在は統合可能)。再生時は各ピッチを同時発音
  - タイ/ハンマリング・プリング/スライドのアーティキュレーション付与(再生にも反映)。タイのみ和音同士(構成が完全一致、ゴースト混在可)にも付与可能。ハンマリング・プリング/スライドは単音同士限定で、スライドのみ弦をまたいだ2音にも付与できる(再生時は2音の周波数間を滑らかに変化させる)
  - 連符(n連符)の付与: 同じ音符長の音符を選択して連符ボタンで一括適用(nは選択数)。ブラケット+数字表示、再生時の長さにも反映
  - 音符のクリック選択(Shiftで範囲選択)による削除・音符長/付点の一括変更・コピー&ペースト
  - Undo/Redo、選択位置からの再生(同時再生時は他TABも拍数を合わせて追従)、メトロノーム、1オクターブ上げ再生オプション
  - 小節線・小節番号の自動表示と、拍子に対して長さが合わない小節の警告表示(赤系背景)
  - TAB譜の数字にキー・スケール・表示モードに応じた配色を反映するオプション
  - TAB譜(1本)のJSON形式でのExport/Import(export時は画面上部の設定=キー・スケール・テンポ・拍子等のスナップショットも同梱。Importは既存TABを上書きせず新規TABとして追加・アクティブ化する。読み込めなかった設定項目がある場合は画面上部にポップアップ通知)、localStorageへの自動保存
  - 折りたたみ式のJSON直接編集エリア(貼り付け・編集内容を即座にTAB譜へ反映。チューニング/フレット数もここで編集可能。再生中は編集不可。選択中/再生中の音符に対応する箇所をJSON側でもハイライト・自動スクロール。音符は1行1音符で整形表示し、小節の区切りには空行を挿入)
- **設定の永続化**: キー・スケール・表示モード・マスター音量・テンポ・拍子・TAB再生オプション(オクターブ上げ・配色連動・メトロノームON/OFF)等をlocalStorageに保存し、次回訪問時に自動復元(チューニング・フレット数はTABごとのデータとして別途保存)
- **TAB JSON形式変換ツール**(`convert.html`、ヘッダーのリンクから遷移): 旧フォーマットのTAB譜JSONを最新フォーマットへ変換(`string`/`fret`直持ち→和音対応の`notes`配列形式、チューニング/フレット数のsettings→tab移行、テンポ/拍子のtab→settings移行)。ファイルアップロードまたはテキスト貼り付けで入力し、変換結果を画面表示・ダウンロードできる
- PC/タブレットでのマウス・タップ操作を想定(スマホ向けレスポンシブ対応は非対応)

## 使い方

下記「ローカルでの動作確認」の手順で静的サーバー経由で `index.html` を開くと利用できます。

操作の流れ:

1. 上部の「キー」「スケール」でハイライトしたいキー・スケールを選択
2. 「チューニングプリセット」で弦構成を選択、または「チューニング詳細設定」から弦の追加/削除・開放音・フレット数を変更(現在アクティブなTABに対する設定)
3. 「表示モード」でスケール構成音表示⇔機能和声(T/S/D)表示を切り替え
4. フレットボード上の丸をクリック/タップすると、その音が再生される
5. 音符長(必要なら付点も)を選んだ状態でフレットボードをクリックすると、下部のTAB譜に音符が追加される。休符・ゴーストノート・アーティキュレーション・削除・Undo/Redo・コピー&ペーストもTAB譜側のツールバーから操作できる
6. TAB譜の「再生」ボタンで作成した譜面を再生。音符を選択しておくとその位置から再生される
7. TAB譜表示上部のタブバーの「+」でチューニングプリセットを選んで新規TABを作成。ベース用・ギター用のように別々のチューニングでTABを使い分けられる。再生ボタン付近の「同時再生」で他TABを選択すると、共通のテンポで同期して同時再生できる

## 技術スタック

- Vanilla JavaScript(ES Modules)+ HTML + CSS
- SVGによるフレットボード描画
- Web Audio API(`OscillatorNode` + `GainNode`)による音声合成・TAB再生スケジューリング
- 外部フレームワーク・ビルドツールは不使用

## ファイル構成

```
/index.html
/convert.html       … TAB JSON形式変換ツール(独立ページ)
/style.css
/js/
  ├ notes.js         … 音名・周波数計算
  ├ scales.js        … スケール定義・ハイライト判定・機能和声判定
  ├ tuning.js        … 弦数・チューニング状態管理、プリセット定義
  ├ storage.js       … localStorage読み書き(設定・TAB譜ライブラリ)
  ├ audio.js         … Web Audio APIによる音再生・マスター音量
  ├ render.js        … フレットボードSVG描画
  ├ tab.js           … TAB譜データモデル・編集操作・Undo/Redo履歴
  ├ tabRender.js     … TAB譜表示エリアのDOM描画
  ├ tabPlayback.js   … TAB譜再生・メトロノームのスケジューリング
  ├ convert.js       … convert.htmlの変換処理(tab.jsのmigrateTabData流用)
  └ main.js          … 初期化・イベントバインド
```

## ローカルでの動作確認

ES Modules(`<script type="module">`)を使用しているため、`index.html` を `file://` で直接開くとブラウザのCORS制約によりモジュール読み込みに失敗します。簡易的な静的サーバーを起動して確認してください。

```bash
# 例: Python
python -m http.server 8000

# 例: Node.js (npx)
npx serve .
```

起動後、`http://localhost:8000` にアクセスします。
